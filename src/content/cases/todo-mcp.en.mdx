## Problem

A task app can be handled through a web interface alone, but exposing the same operations to AI agents adds a second surface that tends to duplicate rules and persistence. This project supports both entry points on a single business layer.

## Role

Personal project. I designed and developed the interface, MCP server, authentication, tests, and architecture documentation.

## Decisions

1. **Dual architecture with one logic layer.** The interface uses Next.js 16 with App Router, React 19, and Server Actions; the MCP server runs on SQLite. Both share the business layer through Prisma and Zod validation.
2. **Five CRUD tools for agents.** The server exposes task creation, reading, updating, and deletion, plus status filters, paginated search, and automatic completion-date updates.
3. **Per-user tokens with revocation.** Authentication uses Better Auth, while MCP tokens are stored as SHA-256 hashes with immediate revocation.
4. **Verifiable quality.** Coverage includes unit, integration, and E2E tests with Vitest and Playwright, along with self-contained interactive architecture documentation.

## Result

The application combines a web interface and an MCP server that operate on the same persistence. The five CRUD tools, filters, paginated search, and completion-date update are covered by tests. The repository is available; the public demo is still pending.
