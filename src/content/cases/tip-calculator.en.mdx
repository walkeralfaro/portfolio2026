## Problem

The Frontend Mentor challenge asked for a calculator that splits the tip and total per person according to the percentage and the number of people. The interface had to adapt to different screen sizes and keep the reset button disabled when there was no tip to calculate.

## Role

Individual development of the challenge with HTML5, SCSS, and vanilla JavaScript. I implemented the calculation logic, the reset-button state, and the responsive layout.

## Decisions

1. **Calculation logic with vanilla JavaScript.** Event listeners read the percentage, bill amount, and number of people, then update the tip and per-person total without relying on a framework.
2. **Conditional reset.** The button is enabled or disabled by combining JavaScript and CSS, so it stays blocked while there is no tip to calculate.
3. **HTML structure and SCSS styling.** I first defined the HTML structure with a layout tool and then handled presentation and responsive adaptation with SCSS.

## Result

The calculator derives the tip from the percentage and the number of people, keeps reset disabled when it does not apply, and adapts to mobile and desktop. The solution is published on Netlify and its code is available on GitHub.
