## Problema

El reto de Frontend Mentor sugería resolver el acortado con una API externa. Para conservar el control del flujo, el proyecto necesitaba un backend propio que acortara enlaces, resolviera códigos y mantuviera la lista después de refrescar el navegador.

## Rol

Desarrollo individual del reto: frontend, backend, persistencia y validación.

## Decisiones

1. **Backend propio en lugar de Clean URI.** Next.js asume el rol full-stack. Una petición GET a `/r/123abc` busca el código en la base de datos, recupera la URL original y valida que sea una dirección real con un esquema Zod.
2. **Persistencia con MongoDB.** Mongoose y MongoDB Atlas guardan los enlaces para que la lista sobreviva al refresco, y la copia al portapapeles se resuelve en un solo clic.
3. **Validación compartida.** Zod se usa en el frontend y en el backend para mantener la misma regla de entrada en toda la pila.

## Resultado

El acortador permite crear enlaces, conserva la lista tras refrescar y resuelve cada código corto mediante el backend propio. El formulario informa cuando el campo está vacío y la interfaz se adapta al tamaño de pantalla. La autenticación, la analítica, las URLs de marca y el seguimiento UTM quedan documentados como trabajo futuro, no como funcionalidad entregada.

## Stack

- Next.js y React
- React Hook Form y Shadcn
- Zod en cliente y servidor
- Mongoose y MongoDB Atlas
