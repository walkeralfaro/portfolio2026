## Problema

Los atajos de teclado suelen quedar repartidos entre notas y documentación. El proyecto reúne esa información en una aplicación local donde se puedan crear, organizar y editar cheat sheets sin depender de una cuenta ni de un servidor.

## Rol

Proyecto personal. Desarrollé la edición, la persistencia local, la vista previa y la salida de impresión.

## Decisiones

1. **Funcionamiento completamente local.** La aplicación no requiere backend: los datos se conservan en localStorage, con múltiples cheat sheets disponibles en el mismo navegador.
2. **Edición y vista previa en la misma superficie.** La edición inline se acompaña de una vista previa en vivo, modo oscuro y una interfaz que mantiene el foco en el contenido.
3. **Impresión pensada como salida.** La vista de impresión se optimiza para generar un PDF en dos columnas, usando Astro, React, TypeScript y Tailwind CSS v4.

## Resultado

Cheatsheet Editor permite administrar varias hojas, editar su contenido en línea, ver el resultado mientras se escribe y preparar una impresión en dos columnas. El código está disponible en GitHub; la demo pública sigue pendiente.

## Stack

- Astro y React
- TypeScript y Tailwind CSS v4
- localStorage
- Impresión PDF a dos columnas
